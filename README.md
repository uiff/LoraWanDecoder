## Verwendung in ChirpStack

### ChirpStack v4 (typisch)
1. In ChirpStack öffnen: **Device profiles**
2. Gewünschtes **Device Profile** auswählen (oder neu erstellen)
3. Zum Tab/Abschnitt **Codec** (oder **Payload codec**) wechseln
4. **JavaScript codec** auswählen (falls Auswahl vorhanden)
5. Den Inhalt der passenden Datei aus diesem Repo kopieren und einfügen
6. Speichern
7. Testen, ob Uplink-Payloads im Event/Telemetry als JSON erscheinen
